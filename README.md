# hub-plugin-sidebar

Плагин страницы [Agents Hub](https://github.com/flagman/agents-hub-core): левый список сессий прячется, как боковая
панель в Jira.

- Кнопка в шапке сессии, левее её имени: нажали — список спрятан, разговор на всю ширину.
- Навели на кнопку — список выезжает поверх ленты и держится, пока мышь над ним; ушли — прячется.
- Закрепить снова — кнопкой в выехавшем списке (справа вверху) или той же кнопкой в шапке.
- Клавиша `[` — то же самое (когда курсор не в поле ввода).
- Выбор помнится в браузере. На узком экране (телефон) плагин ничего не меняет.

Установка: `hub market install libertyswift/hub-plugin-sidebar` (или «Настройки» → «Плагины»).

Только страница: в сеть не ходит, файлов не читает; хранит один ключ `hubx.sidebar` в localStorage браузера.
